# Evaluation Metrics (PRIMARY FOCUS)
The primary evaluation metrics for supply chain simulations are:
- **W_in**: Wasserstein distance on in-distribution test set. This measures distributional fit between simulated and observed trajectories under training conditions (lead_time=2). Lower values indicate better fit.
- **W_out**: Wasserstein distance on out-of-distribution test set. This measures generalization ability when test conditions differ from training (lead_time=5). Lower values indicate better generalization.
- **W_total**: Average of W_in and W_out, providing overall performance metric.

These Wasserstein distances are computed using optimal transport theory (POT library) by sampling states from both simulated and observed distributions at each time step.

Secondary metrics:
- MMD (Maximum Mean Discrepancy): Distribution-level metric using kernel methods
- MSE (Mean Squared Error): Trajectory-level metric
